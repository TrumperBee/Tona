## 4. npm audit

### Baseline (before remediation)

| Command                       | Result                                              |
| ----------------------------- | --------------------------------------------------- |
| `npm audit --omit=dev --json` | 12 vulnerabilities: 4 high, 8 moderate, 0 critical  |
| `npm audit --json`            | 30 vulnerabilities: 5 high, 25 moderate, 0 critical |

Production root causes: `@grpc/grpc-js` <= 1.13.5 via `firebase@13.2.0` → `@firebase/firestore` (GHSA-m9gg-hp2v-232j high, GHSA-f596-whhp-79r4 low); `uuid` < 11.1.1 and Google Cloud transitively via `firebase-admin@13.10.0` (GHSA-w5hq-g745-h8pq moderate).

### Remediation applied

1. `package.json`: pinned `firebase` to `13.4.0` and `firebase-admin` to `14.5.1` (was caret ranges resolving to vulnerable 13.2.0 / 13.10.0).
2. `package.json`: added `"overrides": { "@grpc/grpc-js": "1.14.7" }`. This is required because even `firebase@13.4.0` → `@firebase/firestore@4.20.0` pins `@grpc/grpc-js ~1.9.0`; npm's own suggested alternative was a destructive downgrade to `firebase@9.14.0`.
3. `npm install --no-audit --no-fund` (exit 0), then `npm audit fix --no-fund` (non-forcing; updated lock only: `typescript-eslint` family → 8.74.0, `firebase-tools` → 15.37.0, `minimatch` → 11.0.9 in the ESLint tree, `brace-expansion`, `ignore`, etc.).
4. `npm audit fix --force` was deliberately **not** run: it proposes `firebase-tools@13.11.2`, a breaking major downgrade of the emulator/deploy CLI.

## 5. Rotation guidance

**No rotation is required based on the evidence above**: no credential was found in git history, build output, or tracked files.

Rotate immediately **only if** the ignored local files or deployment environment values were ever shared, pasted into logs/tickets, or committed elsewhere:

1. **Firebase service account** (`FIREBASE_ADMIN_PRIVATE_KEY`, 1736 chars in ignored `.env.local`): create a new key in GCP IAM, replace the deployment secret, then disable/delete the old key. Also revoke any service account key that was present in an earlier local file.
2. **Cloudinary** (`CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`): rotate the API secret in Cloudinary, update deployment secrets, invalidate old credentials.
3. **Resend** (`RESEND_API_KEY`, `RESEND_WEBHOOK_SECRET`) and **Turnstile** (`TURNSTILE_SECRET_KEY`): not present in `.env.local`; if configured in deployment, rotate in the provider dashboard and update hosting secrets.
4. **Email unsubscribe signing secret** (`EMAIL_UNSUBSCRIBE_SECRET`): rotate by changing the deployment value; previously issued unsubscribe links become invalid.
5. **Firebase web API key** (`NEXT_PUBLIC_FIREBASE_API_KEY`): public by design and present in client bundles. Do not treat as a secret; rotate only if abuse is observed, and rely on Firestore rules/App Check for enforcement.
6. `.seed/manifest.json` holds the local batch password and is git-ignored; delete/regenerate it if it was shared. `tests/integration/setup.ts` contains a fake placeholder PEM and needs no action.
