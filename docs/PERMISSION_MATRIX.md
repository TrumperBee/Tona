# Permission matrix

GCC Phase 18A. This table is generated from the source tree and is checked by `npm run test:security`.
It is the single source of truth for actor-driven integration tests.

**Actors**

- **Signed-out**: no session cookie → `401` on protected routes.
- **Signed-in player**: active `user` role; owns only their profile and registrations.
- **Organiser owner**: organiser role and owner of the scoped tournament; another organiser receives `404`.
- **Other organiser**: organiser role but not owner → `404` on tournament-scoped routes.
- **Super Admin**: exact configured UID + email; bypasses ownership but not audit logging.
- **Provider/token**: Svix signature, HMAC unsubscribe token, or browser CSP report; no session.

Statuses in the actor tests are: `401` no session, `403` wrong role, `404` not owned, and `2xx` allowed.
Validation failures on an allowed actor are `400`/`409` and are listed as "allowed (validation)".
